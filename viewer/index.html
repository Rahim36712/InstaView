Saved archive data

Open an export to manage saved data.

Stars, notes, collections, pinned chats and saved searches belong to this export. Backups include your private notes; keep them somewhere you trust. API keys and original message text are excluded. Restore merges saved data for a matching export.

Stars from older versions

Older stars have positions only. They cannot be checked against the original message. Import them into this export only if it is the same archive, then review them in Stars. The original saved positions are retained.

The native launcher already opens its export folder automatically. For folder-picker mode, you can opt in to a local browser copy up to 256 MB. Browser storage can be cleared or evicted.

Retrieval runs locally. When you request AI analysis, selected message excerpts and your key are sent to Google over HTTPS. Your key is saved in this browser's local storage, which is not encrypted. Sources help you check answers; AI can still make mistakes.
